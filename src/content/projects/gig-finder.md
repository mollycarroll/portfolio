## Overview

GigFinder is a full stack web app that enables musicians to find live music venues in a given area for future gigs. Users can search any geographical location (city, neighborhood, or postal code) and get a list of nearby venues.

## Tech specs

- Backend services use OpenStreetMap APIs for geocode location search
- Python web scraping ports venue contact information directly to the search results list
- Users can save selected venues to their account and track contacted status via labels
